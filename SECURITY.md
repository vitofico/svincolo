# Reporting a security issue

Use **Report a vulnerability** under **Security and quality** in the public
Svincolo repository. The form opens a private report for maintainers.
Include the affected version, a short reproduction using synthetic data,
and the expected and observed behavior. Remove credentials, private prompts,
and production identifiers from logs or attachments.

[GitHub's guide to private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)
